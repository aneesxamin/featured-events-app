# Featured Events App

A simple, responsive web app that shows local featured events in a clean, mobile-friendly layout.

## Live Demo

Check it out here: [https://featuredeventsapp.netlify.app](https://featuredeventsapp.netlify.app)

## What it Does

- Shows a top navigation bar with links to Home, Events, and Contact.
- Hero section with the heading: **Discover Events Near You**.
- Featured Events section displaying 3–5 sample events.
- Each event card shows:
  - Event name
  - Date and time
  - Location
  - Short description
  - Register button (just for display)
- Fully responsive for mobile, tablet, and desktop.

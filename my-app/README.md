A responsive single-page React app that displays featured local events. Users can view event details and register (dummy button, no backend functionality).

Features
Top navigation bar with links to Home, Events, Contact
Hero section: “Discover Events Near You”
Featured Events section with event cards showing:
Event Name
Date & Time
Location
Short Description
Register button
Fully responsive for mobile and tablet
(Optional) Search bar to filter events
Event data loaded dynamically from a dummy JSON file
Tech Stack
React (Create React App)
HTML5 / CSS3
JavaScript
